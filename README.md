# HydroRouteC
HYDROROUTE-C is a Flood Relief Routing and Early Warning Engine. It finds safe  routes during floods by avoiding roads with dangerous water levels, and it also  monitors relief camps for food shortages and overcrowding.
Specially for Assam as it is highly affected by floods, so a system like HYDROROUTE-C could help authorities identify safer routes and monitor relief camps. Our prototype can also be expanded in the future using real-time sensor data and larger district level road networks.

Here I used C++ because it provides efficient graph processing, data structures and file handling. These features are useful for implementing Dijkstra’s algorithm, processing road information and storing relief-camp data.
